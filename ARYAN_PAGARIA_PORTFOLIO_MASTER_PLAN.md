# 21. Debugging discipline

When something breaks: 1. confirm browser serves expected file; 2.
inspect Console; 3. inspect Network; 4. inspect DOM; 5. inspect Computed
styles and winning rule; 6. inspect ancestor
positioning/overflow/stacking; 7. inspect script order/runtime state; 8.
inspect animation timeline/style mutations; 9. reproduce with one
controlled diagnostic; 10. fix the smallest root cause; 11. verify
desktop/mobile; 12. remove temporary diagnostics.

Do not solve JavaScript execution errors with CSS opacity hacks. Do not
solve missing assets by redesigning the layout. Do not solve font errors
by replacing the intended font.

Previously used local server URL: `http://localhost:3000`. Confirm the
current port rather than assuming it. Hard refresh: `Ctrl + Shift + R`.
